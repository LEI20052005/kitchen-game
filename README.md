# 厨房小游戏 kitchen-game

一个 2D 竖屏超休闲「煮饭合成」H5 Playable Demo：把食材拖进锅里，按配方炒出菜品，最终做出**葱花蛋炒饭**即通关。

- 引擎：Cocos Creator 3.8.8
- 语言：TypeScript
- 平台：Web / H5（竖屏）

## 玩法

1. 底部食材栏有 7 种基础食材，无限刷新，拖走后自动补货
2. 把食材拖进锅（最多 9 个，3×3 网格），点【炒菜】开始 1.5s 烹饪
3. 配方要求**数量正好**、且不能混入额外食材 → 成功出菜并解锁图鉴；否则产出黑暗料理
4. 成品可以再拖回锅里继续合成，例如：大米+水 → 米饭 → 蛋炒饭 → 葱花蛋炒饭
5. 连败 3 次会询问是否需要菜谱提示；解锁进度保存在 localStorage
6. 做出葱花蛋炒饭 → 通关庆祝

完整配方表见 [开发日志.md](./开发日志.md)。

## 技术要点

- **规则与渲染分离**：`GameConfig.ts` 是纯数据 + 纯函数模块（食材字典、配方表、`matchRecipe()` 匹配），不依赖任何引擎组件，便于单测与后续配置化
- **全代码动态 UI**：图鉴、食材栏、提示层、通关结算屏全部由代码生成，统一处理 `Layers.Enum.UI_2D` 图层与 `Sprite.SizeMode.CUSTOM` 尺寸控制
- **拖拽交互**：基于 `TOUCH_START/MOVE/END/CANCEL` 四件套做坐标空间换算，落点命中锅 / 桌面分别入锅、出锅，否则自动复原
- **状态互斥的反馈层**：锅满 / 成功 / 失败三类全屏提示互斥防叠屏，点击任意处关闭；失败时先放黑烟再弹提示，避免遮罩盖住特效
- **素材与内存优化**：图片统一压缩到最长边 512，74MB → 3.7MB（-95%），纹理内存约 276MB → 约 24MB
- **环境容错**：`localStorage` 可用性探测 + `resources.load` 兜底，兼容编辑器预览与浏览器运行的差异

## 目录结构

```
assets/
  scripts/        # 全部逻辑代码
    GameConfig.ts     # 规则配置：食材字典 + 配方表 + 匹配函数（纯数据/纯函数）
    GameManager.ts    # 场景装配、UI 生成、炒菜流程、图鉴与提示
    IngredientItem.ts # 单个食材的拖拽组件
  UI/             # 22 张游戏素材（已压缩到最长边 512）
  resources/      # 黑烟、星星特效（运行时加载兜底）
  Main.scene      # 主场景
_tools/           # 素材处理脚本（去水印 / 抠图）
```

## 本地运行

1. 安装 [Cocos Creator 3.8.8](https://www.cocos.com/creator)（Dashboard 免费）
2. Dashboard → 导入项目 → 选择本仓库根目录
3. 打开 `assets/Main.scene`，点编辑器顶部「预览」（浏览器）即可试玩

> 编辑器预览运行在 iframe 中，localStorage 可能被拦截；发布到浏览器后一切正常。

## 构建发布

菜单「项目 → 构建发布」，选择 **Web Mobile** 平台，构建完成后产物在 `build/web-mobile/`，可直接部署到任意静态服务器或 GitHub Pages。

## 素材来源

游戏内 22 张素材由 **豆包 AI** 生成，经 `_tools/RemoveBg.ps1` 去水印 / 抠图处理，并统一压缩到最长边 512。
